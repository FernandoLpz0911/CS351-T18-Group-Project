# Install & Run Guide
Make sure you have the following installed:
Python (tested with Python 3.12.3)
pip    (tested with pip 24.0)
django (tested with 5.2.7)
nodejs (tested with v20.19.5)
npm    (tested with 10.8.2)

Installation:

goto/open   "frontend/"      (without quotes) in terminal
run command "npm install"    (without quotes) in terminal
run command "npm audit fix"  (if required by terminal and without quotes) in terminal

recommended you create and use venv for anything pip/python related

goto/open root of project folder
run command  "pip install -r requirements.txt" (without quotes) in terminal


Running the frontend:
Open new terminal
goto/open   "frontend/"   (without quotes) in terminal
run command "npm run dev" (without quotes) in terminal

Running the backend:
Open new terminal
goto/open   "/backend/backendlogic"           (without quotes) in terminal
run command "python3 manage.py runserver"     (without quotes) in terminal, NOTE: if python3 doesn't work, use python

Now, both the frontend and backend should be running.




The following may depend on your local system (If the ports are already in use, it will differ, check your terminal)

frontend should accessible at:
http://localhost:5173/

backend should be accessible at:
http://127.0.0.1:8000/api/
http://127.0.0.1:8000/admin

NOTE: To access the admin for backend you must create a superuser

Open new terminal
goto/open   "/backend/backendlogic"           (without quotes) in terminal
run command "python manage.py createsuperuser" or "python3 manage.py createsuperuser"

it will prompt you to create a username and password, (email is optional).

Use the newly created credetials to access admin page if desired.
